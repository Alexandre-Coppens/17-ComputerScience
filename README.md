# Cpp Sorting Sytems
You can see here the Benchmarks of different Sorting Systems.

**Including:**
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

The Benchmark will be made with Arrays of 1.000, 10.000, 100.000 and 1.000.000.
The will run each **100 times** (not the 1.000.000, only once) in **release mode** to get the **average**, **lowest** and **highest** time in seconds. 
(All the timers will **not** be included)
